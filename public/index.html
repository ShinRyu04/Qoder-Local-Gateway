Proxy API Key

Jika kamu mengisi PROXY_API_KEY di .env, masukkan key-nya di sini agar konsol bisa memanggil proxy. Hanya disimpan di browser ini dan tidak dikirim ke mana pun. Kosongkan jika tidak diisi.

◬

OpenAI Compatible

Untuk klien yang mendukung endpoint kompatibel OpenAI:

{
  "baseUrl": "http://127.0.0.1:3000/v1",
  "apiKey": "your-PROXY_API_KEY"
}
◬

Anthropic Compatible

Untuk klien yang mendukung endpoint kompatibel Anthropic:

ANTHROPIC_BASE_URL=http://127.0.0.1:3000
ANTHROPIC_AUTH_TOKEN=your-PROXY_API_KEY
